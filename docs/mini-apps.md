# Оригинальные публичные демонстрационные карточки Xiaomi

Источник — публичный [официальный каталог Xiaomi](https://m.mi.com/appcard).
Его frontend ссылается на открытый JSON из Xiaomi CDN со100 карточками и прямыми
URL HTML-приложений. Это новый источник, отдельный от16 системных MAML-шаблонов
из Themes/SubscreenCenter и от OTA. Полные SHA трёх выбранных HTML зафиксированы
в `work/research/xiaomi-mini-apps-provenance.json`.

Перенесены побайтно оригинальные публичные HTML:

| ID | Карточка | Исходное поведение |
|---|---|---|
|1|喝水打卡器 — вода|8 стаканов, заполнение стакана/капель, splash и celebration, сохранение сегодняшнего прогресса; следующий день начинает счёт заново|
|3|六级背单词 — английские слова|Оригинальный английско-китайский словарь, выбор20 слов, слово/транскрипция/перевод, «знаю/не знаю», взвешенный повтор незнакомых слов и сохранение прогресса|
|5|番茄专注计时 — Pomodoro|25мин фокуса/5мин отдыха, start/pause/reset/skip, переключение стадий, исходные декоративные анимации и сохранение endAt/remaining|

Первый собственный Canvas-прототип был отклонён пользователем и заменён
оригинальным кодом. Его стакан/счётчик250мл/редактируемая цель и собственный
русский словарь не выдаются за функции этой версии. Китайский текст оригинала
не переведён; водяная цель и словарь сохранены как в источнике. Публичный пример
не считается доказательством идентичного firmware runtime на настоящем18Pro.

В Main нажать **Выбрать мини-приложение**, выбрать карточку и нажать
**На внешний экран**. До Apply меняется только отдельный preview с отключённым
DOM storage; обычный preview в Main также использует этот изолированный режим.
Cancel не влияет на внешний экран/сохранённые данные. **Вернуть
питомца** либо выбор оформления в галерее возвращает прежнее оформление.
Применённые карточки переключаются тремя Android-кнопками над исходным canvas.
При уходе Main в фон открытый диалог закрывается и его WebView уничтожается.

В общей галерее карточки находятся в коллекции **18 Pro**, рядом с донорскими
оформлениями18Pro. Фильтр **Мини-приложения** оставляет только эти три карточки;
поиск и избранное работают внутри выбранной коллекции. Карточка открывает preview,
выбор требует Apply. **Свои** содержит четыре шаблона для фотографии/текста;
неатрибутированные архивные пресеты выделены в **Архив Xiaomi**.

Хост использует Android WebView на всю площадь MIX cover. При загрузке перед
оригинальным скриптом задаются поддерживаемые им CANVAS_W/CANVAS_H: ширина976,
высота по фактическим пропорциям окна. Фон заполняет весь экран; оригинальная
FIT/DX/DY-логика сохраняет равномерный масштаб контента и совпадение касаний.
Диалог показывает такой же портретный preview. HTML в assets не изменяется.
Физическая проверка расположения возле камер MIX ещё нужна.
Фактический cutout учитывается для кнопок хоста; при его отсутствии34% — fallback.
Canvas оригинала имеет ограничения accessibility; нельзя объявлять его полноценно
адаптированным для TalkBack или крупного системного шрифта.

HTML-файлы в assets сохраняют SHA оригинала. Только при загрузке хост добавляет
viewport, CSP и размеры Canvas. Разрешены ровно три bundled asset по выделенному локальному
HTTPS origin. Network loads, file/content access, mixed content, геолокация,
permissions и навигация наружу запрещены. Native JavaScript bridge отсутствует.
INTERNET permission не добавлено. localStorage оригинала находится в private
WebView storage приложения; preview использует другой origin без DOM storage.

Показ карточки освобождает PAG/MP4/bitmap-ресурсы и датчики питомца и останавливает
его250ms ticker/utility overlay. При stop или смене карточки WebView уничтожается,
что завершает JavaScript/rAF/audio этой страницы; глобальный pauseTimers не
используется, чтобы не остановить другой видимый экран. Видимая карточка сохраняет
свои исходные30fps анимации. Их CPU/расход на телефоне ещё не измерены.

Оригинальный Pomodoro использует Date.now/endAt и собственные audio/vibration
вызовы. Это не системный alarm: после уничтожения страницы звук/фоновые переходы
не выполняются; при восстановлении работает исходная load-политика, включая
сброс истёкшей скрытой стадии в состояние ожидания. Защита от смены системного
времени/новой загрузки не добавлена и не подразумевается. Нативный старый utility
timer остаётся независимым. Fold/lock/sleep возвращают stock Xiaomi/AOD.

`python -X utf8 work/tests/run_mini_apps_qa.py` выполняет отдельные27 guarded
emulator-5554 проверок: точные исходные SHA, Apply/Cancel, настоящие MotionEvent
по оригинальному canvas, сохранение/восстановление при пересоздании WebView,
ограничения хоста и уничтожение скрытого renderer. QA использует отдельный
случайный локальный origin и восстанавливает исходные prefs, не меняя пользовательские
данные карточек. Снимки получают через PixelCopy из реально скомпонованного окна, дожидаясь завершения до смены карточки. Снимки, их SHA и отчёт привязаны к точному APK SHA. Это не physical QA.

Xiaomi resources сохраняют ownership и находятся вне MIT лицензии кода порта;
см. `work/app/assets/miniapps/xiaomi/NOTICE.txt`.

## Что найдено в файлах 18 Pro

В доноре подтверждён native JsCanvas/QuickJS runtime и извлечены шесть встроенных
MAML-карточек. Вода/Слова/Pomodoro в этих шести пакетах не найдены; текущие три
HTML остаются публичными веб-примерами, а не firmware extracts. Подробности и
границы поиска: [donor18-mini-app-runtime.md](donor18-mini-app-runtime.md).
