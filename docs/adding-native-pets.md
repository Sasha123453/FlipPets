# Общая геометрия и добавление питомцев

Один персонаж имеет один автоматический размер на внешнем экране в раскрытом
и сложенном состояниях. В раскрытом рисует PetStage, в сложенном — штатный
Xiaomi runtime. Они могут начинать разные сцены: непрерывное продолжение одного
decoder через блокировку не требуется.

Сейчас оба пути подготовлены для шести родных питомцев MIX Flip и Charlie.
Другие записи пока доступны только в приложении. Общая геометрия не импортирует
их автоматически в Xiaomi и не обходит три места для сохранённых питомцев.

## Как устроено размещение

- MIX Flip сохраняет исходные PAG, размеры каждого холста, Zoom и таблицы
  смещения/зеркалирования. И PAG, и часы выбирают0/180 по стороне выреза камер:
  правый непустой вырез даёт2, иначе0, как DeviceConfig.getRotationInCutout.
- AI-композиции описаны в `work/app/assets/native-pet-layout.json`: исходный
  холст, SHA опорной сцены, постоянные scale/X/Y и точка привязки тела справа/снизу.
  NativePetGeometry читает записи для всех сцен; native Charlie использует тот
  же трансформ. Новый профиль не требует отдельного Java switch.
- Размер тела исключает ветки и декорации. Charlie использует guide365,112,812,574
  с целевыми правым краем1140 и низом1392. Матрица не меняется от кадра к кадру.
- Preview рисует тот же виртуальный внешний экран. Скрытие часов сохраняет общий
  размер Charlie. Явные ручные scale/X/Y остаются относительными к общей геометрии
  и могут осознанно изменить раскрытый режим. Сохранённые настройки не сбрасываются.
- Прежняя геометрия других доноров, photos, compositions, MP4 и фоновых эффектов
  сохранена. Они не становятся взаимозаменяемыми native-форматами.

## Следующий PAG-питомец

1. Импортировать исходники с provenance, сохранив bytes, IDs и права владельца.
   Получить реальное декодирование каждой сцены с source SHA, dimensions,
   стабильными PNG и движением.
2. Выбрать постоянный guide тела на декодированных позах, исключив декорации.
   Проверить движение и края. Padding не возвращает отсутствующие пиксели.
3. Подготовить черновик:

   ```powershell
   python -X utf8 work/tests/shared_pet_layout.py --pet CATALOGUE_ID --decode-report work/qa-final/DECODE/decode.json --subject-guide LEFT TOP RIGHT BOTTOM
   ```

   Проверяются SHA всех сцен, размеры, стабильные PNG и RGBA SHA. Разные исходные
   холсты требуют отдельной адаптации. Черновик создаётся в ignored
   `outputs/native-pet/layout-drafts`; действующий профиль и телефон не меняются.
4. После визуальной проверки перенести `layout` под его ID в `layouts` файла
   native-pet-layout.json. Сборка проверяет схему, допустимый каталог и source SHA.
5. Подготовить совместимую native-композицию и постер реального первого кадра,
   используя тот же трансформ. Бинарный writer prepare_native_composite.py пока
   намеренно принимает только проверенный граф Charlie. Другой граф требует
   проверенного адаптера и декодирования результата; снимать этот guard ради
   нового имени нельзя. MP4 и interactive_pets требуют отдельных адаптеров.
6. Проверить APK renderer, preview/Cancel и конкретный штатный preview. Только
   после явного выбора выполнять OEM Apply/update. При полной квоте обновлять
   единственную принадлежащую нам запись; не повторять Add и не удалять чужие.

## Проверки

```powershell
python -X utf8 work/tests/shared_pet_layout.py
python -X utf8 work/tests/run_shared_pet_layout_tests.py
python -X utf8 work/tests/run_native_pet_update_tests.py
python -X utf8 work/tests/run_mixflip_guard_tests.py
python -X utf8 work/build_apk.py
python -X utf8 work/tests/run_mixflip_qa.py
python -X utf8 work/tests/run_pet_layout_qa.py
```

Две последние команды допускают только проверенный emulator-5554. MIX Flip QA
теперь содержит80 проверок: прежние64 и16 проверок Charlie, включая12 сцен,
clockless, ручной draft, Cancel и освобождение. Layout QA сохраняет19 проверок,
проверяя общий native размер вместо старого увеличения Charlie. Отчёты привязаны
к точному installed/current APK SHA.

Физические камеры в движении, notifications, biometric и AOD проверяются отдельно.
Точный автоматический Restore ещё не доказан. Профиль не меняет secure Power
и не решает показ при выключенном основном экране раскрытого телефона.
